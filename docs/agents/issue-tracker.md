# Issue tracker: Linear

Issues and specs for this repo live in **Linear** — the `resume` workspace.

## Conventions

- Issues are created via the Linear **web UI**; the Linear **CLI** is also available if you prefer the terminal.
- Triage state is applied as Linear **labels** (issue labels) — see `triage-labels.md` for the label strings.

## When a skill says "publish to the issue tracker"

Create a new issue in Linear (via the web UI or CLI) and apply the relevant triage label.

## When a skill says "fetch the relevant ticket"

Look up the issue in Linear by its identifier or URL.

## Wayfinding operations

Used by `/wayfinder`. Not currently supported on this tracker — agree a manual alternative with the user if wayfinding is needed.
